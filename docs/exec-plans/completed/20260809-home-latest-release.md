# Title

ホームの最新リリース枠を収録曲リスト主役にする

## Status

completed

## Background

`src/viewer/src/pages/index.astro` の最新リリース枠は `JacketArt` を主役にしている。ジャケット廃止でこの枠が成立しなくなる。

左の最新楽曲は YouTube サムネイル（`i.ytimg.com` 直参照）のまま残るため、右だけが画像を失う。`home-feature-mock.html` で「一覧の行と同じ表現」と「収録曲リスト主役」を比較し、後者を採用した。

なお実際の最新リリースは 1 曲シングルであることが多い（84 グループ中シングルが 45 件）。収録曲が 1 曲しかない場合の見え方が設計上の焦点になる。

## Goal

最新リリース枠からジャケットと大きな色面を外し、左ボーダーで代表色を示しつつタイトルと収録曲を主役にする。

## Scope

- `src/viewer/src/pages/index.astro` の最新リリース枠
- `src/viewer/src/styles/viewer.css` の `.feature-*` 系

## Non-Scope

- 最新楽曲枠（YouTube サムネイルのまま変更しない）
- リリース一覧・詳細・楽曲タイル

## Acceptance Criteria

- 最新リリース枠に画像も大きな色面も無く、左ボーダーで代表色が分かる
- タイトルと収録曲リストが主役になっている
- 収録曲が多い場合、リストは max-height でフェードして切れる
- JavaScript を足していない

## Steps

- [x] `index.astro` の最新リリース枠で、ジャケット位置に代表色の単色面を置き、右にタイトルと収録曲を並べる
- [x] 楽曲ページへ辿れないトラックは沈めた色で描く
- [x] `viewer.css` で単色面と本文を等高にし、収録曲リストに `overflow: hidden` と `mask-image` のフェードをかける
- [x] 最新リリース枠から画像要素を外す。`.feature-art-link` は最新楽曲のサムネ用に残す

## Decision Log

共通の判断は `20260809-release-color-column.md` を参照。

- 2026-08-09: 一覧の行をそのまま置く案ではなく、収録曲リストを主役にする案を採る。`home-feature-mock.html` で比較して決めた
- 2026-08-09: 表示曲数は左の最新楽曲カードの高さに合わせる。実装は CSS のみ。JS で測ると hydration コストが乗り、フォント読み込み前後で高さが変わってちらつくため
- 2026-08-09: 高さ合わせは上限としてのみ効かせ、収録曲が少ないときに右カラムが短くなるのは許容する。`description` は 85 グループすべて空で、余白を埋める材料が無い
- 2026-08-09: 曲数の `slice` は外し、全曲を載せて CSS で切る。件数上限を二重に持つとフェード位置と件数表示が食い違うため
- 2026-08-09: 収録曲リストを左に置く案から、ジャケット位置に単色面・右にタイトルと収録曲を並べる案へ切り替える。最新楽曲枠と同じ左右構造のまま識別子だけ色に替えるほうが読みやすいため
- 2026-08-09: 大きな色面が空のジャケットに見えやすいため、構図を再検討する。
  `home-feature-mock.html` で案1（色面なし）/ 案2（細い帯+小見本）/ 案3（全幅組み直し）を並べ、採用後に本番へ当てる
- 2026-08-09: 案1を採用。大きな色面をやめ、左ボーダーで代表色を示す。
  タイトルと収録曲が主役になり、最新楽曲枠のサムネと「空のジャケット」で並ばなくなるため
